## 1. 来源与允许推进的边界

首要来源：[main_v2_BHH.tex](../paper/main_v2_BHH.tex)，SHA-256 为 `500BE1ADA854317BE79C358E0FF1269786DD4C7EA8E1102B501354EFF04A3457`。行号指本地源码行号，不是编译后的公式号。已读 [MODEL_CONTRACT](../../coordination/MODEL_CONTRACT.md) 与 [V1_M_DECISION_SPEC](../../coordination/V1_M_DECISION_SPEC.md)。本 TeX 没有 `\input`/`\include` 或自定义 `\newcommand`；定理环境在23–29行。这里的计算不需要参考文献文件，不声称已验证 BHH 近似的统计精度。

现在可以实施的纯功能为：给定显式参数计算 f、h、逐弧 K(v)，按正文生成 local/AV 母弧，查询半开占用。它们没有订单、车辆决策、目标函数、滚动信息集、候选弧剪枝和 solver 依赖。调用者必须自己提供并统一物理时间单位；工具不从旧配置推测分钟/小时，不转换 CFS 重量为 stops，也不根据现有订单删除弧。

输出逐弧容量不决定同 start 的不同结束时刻是否组成一个共同 wave。更不允许把同一批车辆的联合容量复制到多个不同 j 的弧上。内核准备完成可以先于 D1–D6 的完整模型解释，二者是不同验收事项。

## 2. 源公式及数学域

| 量 | 源码依据 | 原式与域 |
|---|---|---|
| 城市、时间 | 67行 | k∈{1,2}，节点集 {0,…,T}，一期物理时长 t0 |
| stops | 69行 | 每单位需求对应起点 pickup 和终点 drop-off 各一个 stop |
| f_k(q) | 71行 | a_k q+b_k√q；a_k>0、b_k≥0；实数 q≥0 是平方根自然域 |
| h_k(θ)=f_k⁻¹(θ) | 74行，`eq:bhh inverse` | [(√(b_k²+4a_kθ)−b_k)/(2a_k)]²，θ≥0 |
| local 母弧 | 82行，未另设 label | A_k={(i,j)∈{0,…,T}²: i<j，j−i≤ceil((2ρ_k+f_k(M))/t0)} |
| AV 母弧 | 71、82行 | Ahat={(i,j)∈{0,…,T}²: j=i+τ}；τ是正整数期数，物理时长 τt0 |
| 逐弧 wave 容量 | 82行；106行 `BHH` 使用 | B_ij=[(j−i)t0−2ρ_k]⁺；K_kij(v)=min{vM,h_k(vB_ij)}，原表 v=1,…,N_k |
| 容量的完整模型使用 | 106、110行，`BHH`、`wave link` | Σ_l g≤Σ_v K(v)u_v，x=Σ_v v u_v，Σ_v u_v≤1 |
| 占用 | 82行；89、93行使用 | S_k(t)={(i,j)∈A_k:i≤t<j}；AV 同样半开 |

f、ρ、θ、duration 与 t0 必须使用同一种物理时间单位。a 的量纲为时间/stop，b 为时间/√stop，ρ 为时间，M/K 为 stops，v 为车辆数。内核不读取源77行的费用单位，因此不裁决77与84行的费率量纲问题。

**已证命题（源公式的代数结论）**：a>0、b≥0 时 f 在 q≥0 连续严格递增，值域为 [0,∞)。令 r=√q，解 ar²+br=θ 的非负根便得到74行。因此 h(0)=0，且 f(h(θ))=θ。这里证明的是所给函数的逆，不是车辆路径长度的精确性。

**已证命题（源公式的有限边界）**：B=0 时 K(v)=0；b=0 时 h(θ)=θ/a；0≤K(v)≤vM。当 v>0 时 K(v)/v=min{M,h(vB)/v} 非减：由 θ=a h(θ)+b√h(θ)，可得 h(θ)/θ=1/(a+b/√h(θ)) 随 θ>0 非减，B=0 另行成立。这不证明 K 全域凸或处处严格超线性。b=0、B=0 或 cap 生效均能使严格性失效。

**反例/已否证的普遍命题**：“有正时长的母弧必有正容量”。取ρ=1、t0=1、a=1、b=0、M=1，local上界ceil(2+1)=3；(0,1)、(0,2)均为母弧，但 B=0，K=0。不得在纯母弧工具内自动删除它们。

## 3. 建议纯 API 与输入防线

下列名称是接口建议，实施者可以采用等价名称，但必须公开同样的参数和边界；不可暗中复用旧 loader 的单位默认值。

| 功能 | 显式输入 | 输出/约束 |
|---|---|---|
| `bhh_time` | q,a,b | f(q)；不包含 stem |
| `bhh_inverse` | θ,a,b | h(θ)；不允许负 θ 后自行取正部 |
| `local_capacity` | duration,vehicles,a,b,rho,capacity | min{vehicles×capacity,h(vehicles×max(duration−2rho,0))}；duration已是物理时间，stem只扣一次 |
| `local_arcs` | horizon,t0,a,b,rho,capacity | 与82行一致的(i,j)集合；升序排序方便复现；不接收订单/方向/fleet |
| `av_arcs` | horizon,tau_periods | 所有节点内(i,i+tau_periods)；不把 τ 当物理时间除以 t0 |
| `active_arcs` 或 `is_active` | arc(s), integer time | 按 i≤t<j 判定；不使用 i<t≤j |

建议工具域：所有标量是有限实数、拒绝 bool；a>0，b≥0，rho≥0，capacity=M>0，t0>0，q/θ/duration≥0。vehicles为非负整数；horizon为非负整数，tau_periods为正整数，时间查询节点也必须是非 bool 整数。负数、NaN、Inf、分数车辆/期数必须显式报错，不能裁剪或取整；M=0应报错。车辆数0和horizon0是可方便核验的**工具域扩展**：分别定义 K(0)=0、零时域弧集为空。源表仅列 v≥1；源文没有逐项声明这些输入域。本建议不等于冻结 D4/D6。数学上M=0的公式也有零值，但本次工具合同明确选择正容量并拒绝该输入，不把范围限制说成源文已明确要求。

不建议纯 kernel 引入城市/方向数据结构、OrderBatch、费用参数、配置回退或 N_k 迁入上界。生成 K 表时让调用者显式给待查询 v，不把工具输入上界自动当作完整 V1-F 的正确 selector 上界。

## 4. 数值语义

### 逆函数

直接用源式的 `sqrt(b*b+4*a*theta)-b` 在小 θ、大 b 时相消。代数等价式为

`sqrt(h(theta)) = 2*theta / (sqrt(b*b+4*a*theta)+b)`。

θ=0 应首先返回0；b=0可直接用 θ/a，避免 θ=b=0 的0/0。测试必须代回原函数，或使用高精度/手算 oracle，不能仅比较同一逆函数的两次调用。可用 `hypot(b,2*sqrt(a)*sqrt(theta))` 等缩放办法减少判别式中间溢出；但任何具体浮点实现都应公开其动态范围。不能因所有输入有限就宣称所有中间数/输出必定有限；超出支持范围时显式报错，或先利用 cap 检查绕开无必要的大数逆运算，不能静默返回 NaN。

### ceil 与母弧

严格源定义是 ceil(R)，R=(2ρ+f(M))/t0，随后 max_duration=min(T,ceil(R))。对二进制 float，必须明确采用按实际计算出的 float R 求 ceil 的语义；**没有授权用 `round`、`isclose` 或减 epsilon 把略大于整数的 R 改回该整数**。若用户原意是精确十进制或有理数据，可由未来调用层显式使用 Decimal/Fraction 或预先给已审定的界，这也是独立接口决策。

建议 oracle 用 a=1,b=rho=0,t0=1，M=3 得3；M=`nextafter(3,+inf)` 得4；M=`nextafter(3,0)` 得3。此组输入 f(M)=M，避开其他算术掩盖边界。不要让测试把错误的宽容取整固化为源公式。若 R 很大，先判断 R≥T 后只取 T，可以避免巨大整数 ceil，但不能改变小于 T 的边界。

### 零容量和 cap

即便 duration<2ρ，K=0 也只来自正部公式，不能因此删母弧；工具不判断这个零货量任务是否值得开车。可以先比较 `f(vM)≤vB` 决定 cap 是否绑定（源式的单调等价性），再计算逆，降低无必要的大数运算；仍需处理中间乘积溢出。浮点近饱和只允许公开的测试容差，不允许把容量强行增加到超过 vM。

## 5. 独立手算 oracle 与验收

以下为**已解析计算的数学 oracle，尚非运行结果或 full-model experiment**。

| 案例 | 输入 | 手算预期 |
|---|---|---|
| H1 原式代回 | a=b=1 | f(0)=0，f(1)=2，f(4)=6；h(0)=0，h(2)=1，h(6)=4 |
| H2 无平方根项 | a=2,b=0 | h(3)=1.5，h(0)=0 |
| H3 小θ稳定性 | a=b=1，θ>0极小 | 用 r=2θ/(√(1+4θ)+1) 的高精度 oracle；h(θ)/θ²→1，普通相减式可能错误归零 |
| K1 零tour预算 | duration=2，rho=1，a=b=1，M=10，任意正整数v | B=0，K=0 |
| K2 cap切换 | a=b=1，rho=0，duration=1，M=.5 | K(1)=(3−√5)/2≈.381966；K(2)=1（恰触cap）；K(3)=1.5（严格cap） |
| K3 线性式 | a=2,b=0，duration=3，rho=.5，M=10 | B=2，K(v)=v；验证不是旧式忽略stem后的1.5v |
| K4 零车扩展 | 任意上述合法参数，v=0 | 若接口允许，K=0；无除v或0/0 |
| A1 local上限 | T=4，a=1,b=0,rho=.5,M=1,t0=1 | bound=2；弧恰为(0,1),(0,2),(1,2),(1,3),(2,3),(2,4),(3,4)；其中长1弧K=0仍保留 |
| A2 ceil非整数 | 同A1但M=1.25 | bound=3，须有(0,3)；floor会错误删弧 |
| A3 AV在界内 | T=4,τ=2 | (0,2),(1,3),(2,4)；τ=5则空集 |
| S1 半开占用 | 弧(1,3) | t=0 false，t=1 true，t=2 true，t=3 false；在3释放后同刻启动的另一条弧可占用 |
| U1 单位协变 | a=b=1,rho=.5,duration=2,t0=1，与所有时间系数同乘60 | h的stop结果、K与母弧集均不变；不得只变t0而漏变a/b/rho |

纯测试还应覆盖负输入/NaN/Inf/bool、分数车辆与τ、M=0拒绝与T=0空集、重复调用与排序确定性、θ很小、b=0、恰好cap、τ>T、j=T和整数邻域ceil。测试通过只证明这些纯公式和定义实现一致，不证明 one-hot、货物前置、车辆库存、目标核算、RH跨窗链或理论QVI。
